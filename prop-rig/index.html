Simple prop rig

The short one. Template, global and mover controls, a bind joint, a cleanup pass for the animation department, and a squash block for the bounce.

  • MAYA
  • MUTANT TOOLS
  • PROPS

You can find the Model here

We are going to be using my tools but it’s a simple rig so you can try and replicate it with your knowledge. Mutant Tools

01Prop Template

We need to use the poop template since we can rig any shit with it… its a joke and it’s funny…

02Blocks Explanations

Base A: Will create the Global, Mover controllers

Root: Will create a joint at 0, 0, 0

COG: Is the Center of Gravity Block, put it where the center of the object is, not always on the center of the object, can also be where the assets interact.

ImportMt: doesnt do anything but it’s the import codes of Mutant so you can easily copy and paste them.

Load BLocks, we don’t really use them since its easier from the UI

Unselectable: The geo needs to be in a group called geo for it to work. Will make geo not selectable and give you a couple of attributes to set it selectable again.

Code Block is just there in case you feel like a hacker.

03Build

With building, we just need to worry about the scale of the COG and Global but just scale the CV in case you forget.

04Bind

COG_Bnd will be our bind joint!

05Complete

Go to the Helpers UI and click complete! It will make the outliner and some attrs cleaner for the animation department.

06Bonus: Squash and Stretch

Let’s add a squash block and fill the UI, parent is ginbal COG ctrl and geo is the apple!

Move the Squash_Rig_Grp to match better the shape and you are done!
